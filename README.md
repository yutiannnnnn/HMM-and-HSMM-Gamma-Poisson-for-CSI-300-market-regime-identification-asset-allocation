# HMM-and-HSMM-Gamma-Poisson-for-CSI-300-market-regime-identification-asset-allocation
本项目为学士学位论文的完整代码实现。论文对比了隐马尔可夫模型（HMM）、隐半马尔可夫模型（HSMM-Gamma 和 HSMM-Poisson）在中国股票市场（沪深 300 指数）中的状态识别能力与投资策略表现。  - 样本区间：2005-01-06 至 2026-05-08   - 状态数范围：K = 2, …, 7   - 评估维度：样本内拟合（对数似然、AIC、状态方向一致性 CD）、样本外资产配置表现（年化收益率、夏普比率、最大回撤等）
